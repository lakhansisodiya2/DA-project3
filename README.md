# DA-project3

Data analysis project built with Python, Pandas and NumPy. Covers data cleaning, handling missing values and duplicates, exploratory analysis, and visualization to uncover insights from the dataset.

## Overview

This project is part of my Data Analytics project series ([DA-project1](https://github.com/lakhansisodiya2/DA-project1), [DA-project2](https://github.com/lakhansisodiya2/DA-project2)). The goal is to take a raw dataset, clean it, analyze it, and present the findings clearly.

## Objectives

- Load and inspect the raw dataset
- Clean the data (missing values, duplicates, incorrect data types, inconsistent formatting)
- Perform exploratory data analysis (EDA)
- Visualize key patterns and trends
- Summarize insights from the analysis

## Tech Stack

- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Tools:** Jupyter Notebook / Google Colab, VS Code, GitHub

## Project Structure

```
DA-project3/
│
├── data/            # Raw and cleaned datasets
├── notebook.ipynb   # Main analysis notebook
└── README.md        # Project documentation
```

## Workflow

1. **Data Loading:** Read the dataset into a Pandas DataFrame
2. **Data Inspection:** Check shape, data types, null values and summary statistics
3. **Data Cleaning:** Fix missing values, remove duplicates, correct data types
4. **Exploratory Analysis:** Analyze distributions, groupings and relationships
5. **Visualization:** Create charts to highlight insights
6. **Conclusion:** Summarize key findings

## How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/lakhansisodiya2/DA-project3.git
   cd DA-project3
   ```
2. Install the required libraries
   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```
3. Open the notebook
   ```bash
   jupyter notebook
   ```
